Environment

Put these in Ricky/.env, then restart the server.

GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_REDIRECT_URI=http://127.0.0.1:4173/oauth2callback

ELEVENLABS_API_KEY=sk_...
ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM

# Optional: let an ElevenLabs agent dial natively
ELEVENLABS_AGENT_ID=...
ELEVENLABS_AGENT_PHONE_NUMBER_ID=...

# Optional: call and play the generated MP3
TWILIO_ACCOUNT_SID=AC...
TWILIO_AUTH_TOKEN=...
TWILIO_FROM_NUMBER=+15550100

# Needed by Twilio to fetch audio (ngrok https URL)
PUBLIC_BASE_URL=https://your-tunnel.ngrok.app
